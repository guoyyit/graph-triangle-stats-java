# graph-triangle-stats-java

本地图三角计数与聚集系数统计服务。服务以事件流方式接收边的新增 / 删除，
增量维护按节点、按边、按全图三种粒度的三角计数，以及节点级与全图级的聚集系数，
并支持崩溃恢复与有界内存容量控制。

## 构建与运行

```bash
mvn test          # 运行全部测试
mvn spring-boot:run
```

## 事件语义

事件为无向边操作：`{"type": "ADD" | "REMOVE", "u": <long>, "v": <long>}`。

- **到达顺序即生效顺序**：事件允许乱序到达，服务不重排事件，一律按提交（到达）顺序
  应用到当前图状态。先到的 `REMOVE` 对不存在的边是空操作，后到的 `ADD` 仍会生效。
- **去重语义（状态幂等）**：`ADD` 一条已存在的边、`REMOVE` 一条不存在的边均为空操作，
  因此重复提交同一事件不会改变任何统计结果（响应中的 `ignoredEvents` 会计为空操作数）。
- **节点约束**：节点 id 必须为非负 long；禁止自环（`u == v`）。
- **分批无关性**：同一事件序列无论按何种分批方式提交，只要各批均被接受，
  最终统计结果完全一致。容量校验针对整批应用后的精确状态进行，
  不依赖批内中间状态。

## 批量提交与版本号

- 每次 `POST /api/graph/events` 提交一个批次，批次**原子生效**：批内任一事件校验失败
  （自环、非法 id、空批次）或整批应用后会超出容量上限时，整批被拒绝，
  不产生任何部分效果，也不消耗版本号。
- 每个成功提交的批次获得一个**单调递增的版本号**（从 1 开始，逐批 +1）。
  所有查询响应中的 `version` 表示该结果对应的已提交版本，可用于定位与恢复核对。

## 崩溃恢复

- 每个批次在应用到内存之前先以追加记录（magic + 版本 + 事件 + CRC-32）写入 WAL
  并 `fsync`，记录落盘即视为已提交。
- 重启时从 WAL 重放全部已提交批次恢复状态；文件尾部不完整或校验和失败的记录
  （崩溃造成的撕裂写）会被截断丢弃——已提交事件不会重复应用，未提交事件不会生效，
  恢复后的统计与崩溃前完全一致，且后续版本号从最近已提交版本继续递增。

## 容量上限

内存占用由配置项硬性约束，超出即拒绝，绝不静默丢弃事件：

| 配置项 | 默认值 | 含义 |
| --- | --- | --- |
| `graph.max-vertices` | 1000000 | 最大节点数（至少有一条边的节点） |
| `graph.max-edges` | 10000000 | 最大边数 |
| `graph.wal-path` | `data/graph-wal.log` | WAL 文件路径 |

超限时整批被拒绝，HTTP 返回 `413` 且错误码为 `CAPACITY_EXCEEDED`，
与参数校验失败的 `400` / `VALIDATION_FAILED` 明确区分；被拒绝后服务状态保持不变，
删除边释放容量后即可继续写入。

## 一致性保证

写入持独占锁，批次提交（校验 → 写 WAL → 应用）为原子临界区；查询持共享锁，
因此并发读写时任一查询返回的都是某个已提交版本的完整快照，
不会观察到批内部分事件已应用、部分未应用的中间状态。

## API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `POST` | `/api/graph/events` | 提交事件批次，返回 `{version, appliedEvents, ignoredEvents}` |
| `GET` | `/api/graph/nodes/{id}` | 节点三角计数、度数与局部聚集系数 |
| `GET` | `/api/graph/edges?u=&v=` | 边是否存在及其参与的三角数 |
| `GET` | `/api/graph/global` | 全图三角数、wedges、全局 / 平均局部聚集系数与版本号 |

聚集系数定义：局部系数为 `2·t(v) / (deg(v)·(deg(v)-1))`（度 < 2 时为 0）；
全局系数（transitivity）为 `3·triangles / wedges`，其中 wedges 为连通三元组数
`Σ C(deg(v), 2)`；空图时两者均为 0。

错误响应格式：`{"code": "VALIDATION_FAILED" | "CAPACITY_EXCEEDED" | "MALFORMED_REQUEST", "message": "..."}`。
